# Vision: Got Five!

## Product Goals
- Create an engaging number-based game.
- Demonstrate high-quality PWA development.

## Experience Principles
- Fast, responsive, and reliable.
- Accessible and fun.

## Technical Direction
- Vite + SvelteKit + TypeScript.
- Bun for package management.
- Playwright for E2E testing.
- Redux for state management.
- WebRTC for P2P multiplayer.
- Nix for reproducible environments.
- Plain Svelte-scoped CSS (no Tailwind).

## Near-term Milestones
- Repository setup.
- Basic game mechanics.
- PWA features.
